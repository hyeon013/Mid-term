# 오늘 뭐 먹지? 메뉴 추천 프로그램

랜덤 추천과 조건별 메뉴 검색, 메뉴 관리, 식사 기록 및 지출 통계를 제공하는
Python 데스크톱 프로그램입니다.

## 실행 방법

1. Python 3.10 이상을 설치합니다.
2. `menu.py`와 `menus.json`을 같은 폴더에 둡니다.
3. 해당 폴더에서 다음 명령을 실행합니다.

```text
python menu.py
```

Tkinter가 포함된 Python 설치가 필요합니다. 별도의 Python 패키지는 사용하지
않습니다.

## 주요 기능

- **메뉴 추천:** 랜덤 추천과 예산, 음식 종류, 맵기, 식사 방식, 면·빵·밥 등
  주식, 국물 유무, 따뜻한 음식·차가운 음식 조건 검색을 지원합니다. 짠맛,
  단맛, 매운맛, 담백한 맛은 여러 개를 함께 선택할 수 있습니다. 랜덤 추천 후
  다시 추천을 눌러 메뉴를 바꿀 수 있습니다. 메뉴를 간편식·야식·식사·간식으로
  구분해 검색할 수 있으며, 한 메뉴에 여러 구분을 지정할 수 있습니다. 최근 7일
  안에 먹은 메뉴 제외와 채식·비건 식단 태그 필터를 사용할 수 있습니다.
  화면의 현재 메뉴 결과는 이름·예상 가격·음식 설명을 CSV 파일로 저장할 수
  있습니다.
- **주변 식당:** 주변 식당 탭에서 Google 지도를 열어 현재 위치 주변의 식당을
  음식 종류별로 검색할 수 있습니다. 위치 접근은 Google 지도와 브라우저가
  처리하므로 브라우저의 위치 권한이 필요할 수 있습니다. 이 프로그램은 현재
  위치를 읽거나 저장하지 않습니다.
- **즐겨찾기:** 추천 메뉴를 별도 목록에 추가하고, 즐겨찾기에서 다시 추천하거나
  식사 기록을 남길 수 있습니다. 변경 사항은 `favorites.json`에 저장됩니다.
- **메뉴 관리:** 메뉴를 추가·수정·삭제하고 설명과 PNG/GIF 사진을 등록할 수
  있습니다. 사진은 `menu_images` 폴더에 저장되고 메뉴 상세 화면에 표시됩니다.
  JSON 또는 CSV 메뉴 파일을 불러와 검증한 뒤 현재 메뉴 목록을 교체하고
  `menus.json`에 저장할 수 있습니다. ZIP 백업에 등록 사진도 포함됩니다.
- **식사 기록:** 추천 목록에서 메뉴를 선택하고 실제 지출액을 기록합니다.
  먹은 장소, 함께한 사람, 다시 먹고 싶은지와 자유 메모를 함께 저장합니다.
  기록은 `meal_history.json`에 저장되며, 기록 탭에서 선택한 항목의 메모를
  확인하거나 기록을 삭제할 수 있습니다.
- **통계:** 전체 기록, 최근 14일 일별 기록, 최근 12개월 월별 기록을 선택해
  식사 횟수와 총·평균 지출, 지출 그래프, 음식 종류별 선호도 및 지출,
  자주 먹은 메뉴를 확인할 수 있습니다.
- **내보내기 및 백업:** 식사 기록을 스프레드시트에서 열 수 있는 UTF-8 CSV로
  내보내며 장소, 동행, 재주문 여부와 메모도 내보냅니다. 메뉴·사진·기록·
  즐겨찾기는 ZIP으로 백업할 수 있습니다.

## 메뉴 데이터 형식

`menus.json`은 메뉴 객체의 JSON 배열입니다. `description`은 생략 가능한
설명 문자열입니다. `diet_tags`, `meal_categories`, `image`도 선택 항목이며 메뉴
편집 화면에서 입력할 수 있습니다. 사진은 PNG/GIF 형식으로 등록되며 앱이
`menu_images` 폴더에 복사하고 상대 경로를 저장합니다. 메뉴 구분은
`간편식`, `야식`, `식사`, `간식` 중
필요한 항목을 지정합니다. 주식은 `면`, `빵`, `밥`, `기타` 중 하나이며,
`has_soup`은 JSON 참/거짓 값, `temperature`는 `따뜻한` 또는 `차가운`입니다.
맛 특징은 아래 네 가지 값 중 필요한 항목을 목록으로 지정하며 여러 특징을 함께
선택할 수 있습니다.

CSV로 메뉴를 불러올 때는 첫 행에 `name`, `price`, `category`, `meal_type`,
`spice_level`, `staple`, `has_soup`, `temperature` 열이 필요합니다.
`tastes`, `diet_tags`, `meal_categories`, `image`, `description`은 선택 열입니다.
목록 열은 `|` 또는 JSON 배열로 구분하고, `has_soup`은 `true`/`false` 또는
`있음`/`없음`으로 입력합니다. 필수 값이 잘못된 행은 건너뛰며, 불러오기 전에
유효 메뉴 수와 검증 경고를 확인할 수 있습니다.

바로 가져와 시험해 볼 수 있는 6개 메뉴 예시는 [`menu_examples.json`](./menu_examples.json)
및 [`menu_examples.csv`](./menu_examples.csv)에 있습니다. 메뉴 관리 탭에서
**메뉴 파일 불러오기 (JSON/CSV)**를 누르고 둘 중 하나를 선택하세요. 가져오기는
현재 메뉴 목록을 교체하므로, 기존 목록을 보존하려면 먼저 백업하세요.

```json
{
  "name": "비빔밥",
  "price": 10000,
  "category": "한식",
  "spice_level": 1,
  "meal_type": "집밥",
  "meal_categories": ["식사"],
  "staple": "밥",
  "has_soup": false,
  "temperature": "따뜻한",
  "tastes": ["salty", "spicy"],
  "description": "여러 채소와 밥을 고추장에 비벼 먹는 메뉴."
}
```

`tastes`에는 `salty`(짠), `sweet`(달달한), `spicy`(매운), `mild`(담백한)를
사용합니다. 선택 항목인 `diet_tags`에는 `vegetarian`(채식), `vegan`(비건)을
목록으로 지정합니다. 가격은 양의 정수, 맵기 단계는 `0`부터 `3`까지의 정수여야 합니다.
필수 데이터가 누락되거나 잘못된 메뉴는 불러올 때 안내하고 추천 대상에서
제외합니다. 프로그램이 메뉴와 식사 기록 파일을 같은 폴더에 저장하므로
파일을 삭제하기 전에 필요한 데이터를 백업하세요.

식사 기록에는 장소(`location`), 함께한 사람(`companions`), 다시 먹고 싶은지
여부(`want_again`), 자유 메모(`note`)가 추가로 저장됩니다. 기존 기록 파일에서
이 항목이 빠져 있어도 기록은 그대로 불러옵니다.

식단 태그는 메뉴의 선호 분류로, 실제 조리법이나 알레르기 안전을 보장하지
않습니다. 알레르기가 있다면 주문 전 실제 재료와 조리 환경을 반드시 확인하세요.
