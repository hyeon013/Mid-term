# 오늘 뭐 먹지? 메뉴 추천 프로그램

랜덤 추천과 조건별 메뉴 검색, 메뉴 관리, 식사 기록 및 지출 통계를 제공하는
Python 데스크톱 프로그램입니다.

## 실행 방법

1. Python 3.10 이상을 설치합니다.
2. `menu.py`와 `menus.json`을 같은 폴더에 둡니다.
3. 해당 폴더에서 다음 명령을 실행합니다.

```text
python menu.py
```

Tkinter가 포함된 Python 설치가 필요합니다. 별도의 Python 패키지는 사용하지
않습니다.

## 주요 기능

- **메뉴 추천:** 랜덤 추천과 예산, 음식 종류, 맵기, 식사 방식, 면·빵·밥 등
  주식, 국물 유무, 따뜻한 음식·차가운 음식 조건 검색을 지원합니다. 짠맛,
  단맛, 매운맛, 담백한 맛은 여러 개를 함께 선택할 수 있습니다. 랜덤 추천 후
  다시 추천을 눌러 메뉴를 바꿀 수 있습니다.
- **메뉴 관리:** 메뉴를 추가·수정·삭제하고 설명을 입력할 수 있습니다.
  변경 사항은 `menus.json`에 저장됩니다.
- **식사 기록:** 추천 목록에서 메뉴를 선택하고 실제 지출액을 기록합니다.
  기록은 `meal_history.json`에 저장되며, 기록 탭에서 선택한 항목을 삭제할 수
  있습니다.
- **통계:** 전체 기록, 최근 14일 일별 기록, 최근 12개월 월별 기록을 선택해
  식사 횟수와 총·평균 지출, 지출 그래프, 음식 종류별 선호도 및 지출,
  자주 먹은 메뉴를 확인할 수 있습니다.

## 메뉴 데이터 형식

`menus.json`은 메뉴 객체의 JSON 배열입니다. `description`은 생략 가능한
설명 문자열이며, 나머지 필드는 필수입니다. 주식은 `면`, `빵`, `밥`, `기타`
중 하나이며, `has_soup`은 JSON 참/거짓 값, `temperature`는 `따뜻한` 또는
`차가운`입니다. 맛 특징은 아래 네 가지 값 중 필요한 항목을 목록으로 지정하며
여러 특징을 함께 선택할 수 있습니다.

```json
{
  "name": "비빔밥",
  "price": 10000,
  "category": "한식",
  "spice_level": 1,
  "meal_type": "집밥",
  "staple": "밥",
  "has_soup": false,
  "temperature": "따뜻한",
  "tastes": ["salty", "spicy"],
  "description": "여러 채소와 밥을 고추장에 비벼 먹는 메뉴."
}
```

`tastes`에는 `salty`(짠), `sweet`(달달한), `spicy`(매운), `mild`(담백한)를
사용합니다. 가격은 양의 정수, 맵기 단계는 `0`부터 `3`까지의 정수여야 합니다.
필수 데이터가 누락되거나 잘못된 메뉴는 불러올 때 안내하고 추천 대상에서
제외합니다. 프로그램이 메뉴와 식사 기록 파일을 같은 폴더에 저장하므로
파일을 삭제하기 전에 필요한 데이터를 백업하세요.
